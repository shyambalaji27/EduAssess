Comprehensive Features

Engineered for Seamless Academic Assessments

From flexible question authoring to instantaneous scorecards, everything runs effortlessly inside your browser.

⏱️

Real-Time Proctored Timer

Interactive countdown timer with warning alerts, auto-submission upon expiry, and seamless recovery across page refreshes.

⚡

Instant Automatic Evaluation

Automated scoring engine supporting Multiple Choice, True/False, and complex Multiple-Select questions with strict set verification.

🎨

5-State Question Palette

Color-coded question navigation indicating Answered, Not Answered, Not Visited, Marked for Review, and Answered & Marked.

📊

Visual Analytics & Reports

Performance charts via Chart.js, pass/fail distributions, downloadable candidate answer sheets, and one-click CSV export.

🔒

Role-Based Access Control

Strict separation between Admin and Student sessions. Students can only review their own scores and attempts.

💾

Robust LocalStorage Persistence

Complete database-free operation. Full JSON backup and restore capabilities ensure zero data loss across sessions.

Workflow

How EduAssess Operates

01

Admin Sets Up Exam

Author questions in the Question Bank, define marks, set duration, schedule windows, and publish exams.

02

Student Attends Exam

Students log in with their Student ID, review guidelines, and take timed examinations with live question palette tracking.

03

Automatic Evaluation

Upon submission or time expiration, the JS engine calculates obtained marks, percentage, and pass/fail status immediately.

04

Review & Export

Students view question-by-question explanations; administrators inspect cohort analytics and download CSV reports.

Pure Frontend Engineering

100% Client-Side Web Application

EduAssess is constructed strictly adhering to frontend standards using HTML5, CSS3, Vanilla JavaScript, and the Browser’s Storage API. It requires no Node.js backend, no SQL database, and no server APIs, making it immediately deployable to GitHub Pages, Netlify, or any static hosting service.
